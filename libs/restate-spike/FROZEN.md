# FROZEN — Runtime Selection Evidence

This package is retained as evidence supporting ADR-028 (Durable Execution Substrate Selection).

**Do not add production features or continue candidate development here.**
Production Temporal implementation belongs in the production runtime package defined by ADR-029.

## Allowed changes

- Correctness fixes required to preserve existing evidence
- Dependency / security maintenance
- Test repairs caused by repository-wide changes

## Not allowed

- New runtime capabilities
- Production Temporal topology
- New Restate evaluation
- Feature expansion
